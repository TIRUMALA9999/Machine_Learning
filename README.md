## 📌 Overview

This repository contains **hands-on Machine Learning projects and conceptual notes** developed as part of a Machine Learning course.  
The work focuses on **core supervised learning algorithms**, **model optimization**, and **evaluation techniques** that form the foundation for Data Science and AI roles.

The repository demonstrates:
- End-to-end ML workflows using **Python and scikit-learn**
- Clear understanding of **regression and classification algorithms**
- Mathematical intuition behind **gradient descent**
- Practical application of ML models to real datasets
